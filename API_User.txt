BAZAARPE API DOCUMENTATION

Base URL: http://127.0.0.1:8000
Content-Type: application/json
Auth: Bearer token or Cookie (auth_token). Tokens do not expire.


1. SEND OTP
POST /api/user/send-otp/

Request:
{
  "mobile_number": "9876543210"
}

Response (New User):
{
  "success": true,
  "action": "REGISTER",
  "otp_debug": "123456"
}

Response (Existing User):
{
  "success": true,
  "action": "LOGIN",
  "otp_debug": "123456"
}


2. REGISTER USER
POST /api/user/register/

Request:
{
  "full_name": "Ramesh Patel",
  "mobile_number": "9876543210",
  "email": "ramesh@example.com",
  "address": "Plot 45, Sector 18",
  "pincode": "400703",
  "city": "Mumbai",
  "otp": "123456"
}

Response:
{
  "success": true,
  "token": "TOKEN_KEY",
  "user": {
    "id": 1,
    "user_id": "USR-1001",
    "full_name": "Ramesh Patel",
    "mobile_number": "9876543210",
    "email": "ramesh@example.com",
    "address": "Plot 45, Sector 18",
    "pincode": "400703",
    "city": "Mumbai"
  }
}
Note: Sets cookie "auth_token" automatically (non-expiring).

6. LOGOUT
POST /api/user/logout/
Header: Authorization: Bearer <token> (or automatic via cookie)

Response:
{
  "success": true,
  "message": "User successfully logged out"
}
Note: Clears cookie and deletes token.

11. UPDATE SAVED ADDRESS
PUT /api/user/addresses/<id>/
Header: Authorization: Bearer <token> (or automatic via cookie)

Request:
{
  "house_no": "Penthouse 501, Oakwood Residency",
  "landmark": "Opposite Starbucks, 100 Feet Road"
}

Response:
{
  "success": true,
  "message": "Address updated successfully",
  "address": {
    "id": 1,
    "house_no": "Penthouse 501, Oakwood Residency",
    "landmark": "Opposite Starbucks, 100 Feet Road"
  }
}


12. DELETE SAVED ADDRESS
DELETE /api/user/addresses/<id>/
Header: Authorization: Bearer <token> (or automatic via cookie)

Response:
{
  "success": true,
  "message": "Address deleted successfully"
}
